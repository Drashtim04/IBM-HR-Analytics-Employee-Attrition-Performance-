

# Employee Attrition Analysis & Prediction

A data-driven analytics and machine learning project focused on **analyzing employee attrition patterns** and **predicting employee turnover** using statistical analysis, data visualization, and multiple classification models. The project combines **exploratory data analysis (EDA)**, **Tableau dashboards**, and **machine learning model comparison** to derive actionable HR insights.

---

## Project Overview

Employee attrition is a critical challenge for organizations, directly impacting productivity and costs. This project analyzes HR data to identify key factors contributing to attrition and evaluates multiple machine learning models to predict whether an employee is likely to leave the organization.

---

## Dataset

* **Dataset:** IBM HR Analytics Employee Attrition & Performance
* **Source:** Kaggle
* **Records:** 1,470 employees
* **Features:** 35 employee-related attributes (demographics, job role, satisfaction, income, experience, etc.)

---

## Objectives

* Perform data cleaning, preprocessing, and feature engineering
* Identify patterns and trends influencing employee attrition
* Visualize insights using Tableau dashboards
* Build and compare multiple ML classification models
* Evaluate model performance using standard metrics

---

## Data Preprocessing

* Removed redundant and constant columns
* Handled missing values and data inconsistencies
* Detected and removed outliers using the **IQR method**
* Encoded categorical variables using **Label Encoding**
* Applied **Min-Max Scaling** to normalize numerical features

---

## Data Visualization (Tableau)

Key visual insights include:

* Gender and marital status distribution
* Department-wise and role-wise employee count
* Average monthly income by department and job role
* Age and experience trends across departments
* Attrition-related demographic and job-level patterns

These dashboards help uncover workforce structure, imbalance, and risk areas.

---

## Machine Learning Models Used

The following classifiers were implemented and compared:

* Logistic Regression
* Random Forest Classifier
* Support Vector Machine (SVM)
* Decision Tree Classifier
* K-Nearest Neighbors (KNN)

---

## Model Evaluation Metrics

Each model was evaluated using:

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix

A comparative analysis was performed to identify the best-performing model for attrition prediction.
